## 正答の数え方（問い合わせ結果 r、正解の型の集合 G）
- **正答**: `r.top` が空でなく、`r.top ∩ G ≠ ∅`、かつ `len(r.top) <= max(1, len(G))`。
- **誤決定**: `len(r.top) == 1` かつ `r.top[0] ∉ G`。
- それ以外（複数候補で正答でない・空）は「残り」。

## 内容語（L1）
fugashi（unidic-lite）で分かち書きする。使うのは分かち書き・pos1・pos2・orthBase だけ（pos3・pos4 は使わない）。
- `名詞` は pos2 ∈ {普通名詞, 固有名詞, 数詞}。
- `動詞` と `形容詞` は、直前が接続助詞の「て」「で」のもの、および直前が名詞の「する」（orthBase が する）を除く全部。
- `形状詞` は pos2 = 一般。
- 問い合わせる語は orthBase（無い場合は表層）。lemma は使わない。
- 名詞には文脈を付ける: `context_role` = 直後の語が助詞で `が を に で へ と から まで より の は も` のどれかならその表層、
  `context_predicate` = 後ろで最初に現れる動詞の orthBase。動詞・形容詞・形状詞には文脈を付けない。
- 取り分け: 種 20261003。jawiki は本文のある行（1,501,518 行）から `random.Random(20261003).sample` で 1,000 行、文 = 括弧の外の最初の「。」まで。
  codex は 8 DB の全行を（系列名の辞書順, rowid）で並べた順を同じ種で並べ替え、第 1 行の第 1 文に仮名・漢字が 1 字も無い行を飛ばして 1,000 行。

## 受入基準（ticket W3-a の L1〜L7 の数値をそのまま）
- **L1**: 配置された内容語（`origin=="direct"` かつ `top!=[]` の見出し語の異なり）の数を報告する。目標 100,000 以上。届かなければ段ごとの件数で上限を示す。
  取り分けた 2,000 文の内容語の出現（トークン）のうち `top != []` の割合 ≥ 0.90（直接＋推定）。異なり語での割合も参考に出す。
- **L2**（型の正解つき語彙。種と重なる語は分母から除く。除いた後でも 800 語以上・罠 100 語以上）:
  正答率 = `origin=="direct"` かつ 正答 の件数 / 分母 ≥ 0.85。誤決定率 = `origin=="direct"` かつ 誤決定 / 分母 ≤ 0.08。
  語末の罠の部分集合で誤決定率 ≤ 0.05。参考として推定に回った語の正答・誤決定も別に出す。
- **L3**（未知語。文脈つきで問い合わせる）: 型が決まるべき語（150 語以上）で 正答率 ≥ 0.65、誤り率 ≤ 0.15。誤り = 正答でもなく `top==[]` でもないもの。
  「分からない」が正解の語（50 語以上）で `top != []` の割合 ≤ 0.20。未知語のどれかが表記の規則以外で `origin=="direct"` で返ったら L3 は不合格（除外の失敗）。
- **L4**: 証拠が割れる語が複数候補で返る・推定に「推定（構成）」の印（`constructed: true`）が必ず付く・配置が無い状態が型で返るテスト。
- **L5**: 小さな合成材料での単体テスト（決定的）。実データでの作成が完走し manifest の件数が合う。作成時間と配置の大きさを報告する。
  実行時（問い合わせ）は読み込み済みの 1 プロセスで 1 語あたり平均 ≤ 50 ms かつ 95 パーセンタイル ≤ 50 ms。最大値と入口のコマンド 1 回の所要時間も報告する。
- **L6**: 重み・学習済みモデル・外部の辞書データ・LLM を使っていない（使った材料の一覧を manifest に書く）。既存テストに新しい失敗が無い。
- **L7**: 文書の数値がすべて `artifacts/w3-a/` から再計算できる。型ごと・証拠の種類ごとの正誤の内訳と、間違えた語の一覧を付ける。
