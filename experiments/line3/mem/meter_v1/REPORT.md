## 1. 採点の取り決め（ハーネス変更ではなく、この報告の集計規則）

- 矛盾「発見」: ハーネスの `noticed`（ある report の 1 対が、その仕掛けの message_refs のうち 2 つの異なるメッセージに当たる）。36 = 6 件 × 6 課題。反転（reversal, 2 件 × 6 課題 = 12）は仕掛けの別種なので別列。誤報 = 矛盾・反転のどれにも当たらない報告対を、当たる仕掛けの種類（更新 / 列挙の罠 / 繰り返し / どれでもない「その他」）で分類。
- 回答: ハーネスの `hit` は矛盾質問で「ちょうど金の 2 値」の contested を要求し、A1 は値に「田中 (1-1)」のようにターン番号を付けて答えるため、A1 の矛盾質問が全て不一致になる（生 hit 43.0/60 対 実質 55.0/60）。そこで**末尾の括弧注記を落とす lenient 採点**を主表にし、生 hit も併記する。矛盾質問: contested でちょうど 2 値 = 正解、2 値を含み他の値も足した = 過広（superset。同じ slot の別の矛盾が混ざる）、それ以外の回答 = 誤答。更新・平文: value 一致 = 正解。none = 棄権。「確信した誤答」= none でも正解でも過広でもない回答（更新・平文質問を contested で答えたものを含む）。
- 質問は run ごとにシャッフル（全 arm で同順）。1 セルあたり 3 回。以下の「平均（最小–最大）」は 3 回の反復の 6 課題合計（または課題別）。

## 正直な読み

- **n = 3/セル、課題 6 件（全て同一の著者 codex の合成課題、文は短く 1 session 8–10 通、全体 26 通）、モデルは Haiku 5.5 のみ、プロンプトは 1 版**。一般化できない。A1 が強い理由の一つは、物語が短くて log が全文読める（`log_read` は最新 30 行）こと。log は件数が増えれば効かなくなる。長い物語・多数の文での優劣は未測定。
- **結果は構造の「考え方」の否定ではなく、この実装がこの bank5 の文の形に合わないことの測定**。bank5 の質問対象文は「XのYはA」型が 18 % しかなく、融合 slot が 60 %。構造は書き直しに依存し（拒否 30 %、書き直されず 43 %、学習なし）、自問は 67 % 読めず、読めない 3 課題で SAME_QUESTION はほぼ 0。読める課題でも構造の検知は 36 件中 14.3 件。
- **回答側の失敗は大きい**（棄権 29/60）。記憶に値は入っている（98 % 以上）のに、回答 run が質問の言い方で引けない。これは計器の半分（回答）が構造の読み出しの弱さ（融合 slot の slot 名不一致、主題の二重前置）で決まっていることを示し、「構造が検知する力」と「構造が文脈を拡張する力」の両方が同じ原因で落ちている。プロンプトの例（3 つ）を増やす、主題を回答 run にも渡す、質問語を主題つきで言い換えさせる、は未試行の改善候補で、この報告では測っていない。
- **A2 と A2b の差は測れていない**。差が出た箇所（反転、T03）は n = 3 では誤差と区別できない。注記が REVERSAL のように発火率の高い規則を含むと、誤報も増える。
- **採点の注意**: 主表の回答は lenient（括弧注記を落とす）採点。ハーネスの生 hit は A1 を過小に出す（43.0 対 55.0）。矛盾の「発見」は報告対が仕掛けの message_refs 2 通に当たるかで機械判定しており、同一メッセージが複数の仕掛けに現れる場合に寛容側へ倒れうる。誤報の「その他」13 件（A2/A2b 計）は、仕掛け外の本物の矛盾の可能性を個別には確認していない（audit で 9 件除去済み）。
- **費用**: A2 の入力トークンが多いのは write 結果（十字の JSON）が会話に積まれるため。prompt cache は未使用（`cache_read_input_tokens` 0）。1 run あたり A0 7.5 万 / A1 24 万 / A2b 220 万 / A2 262 万。72 run の合計は入力約 9,245 万・出力約 57 万トークン、壁時間は合計 133 分（2 並列で実時間約 1.5 時間）。金額は Haiku 5.5 の料金を確認していないため出していない。
- **ハーネスで気づいたが直していないこと**（`verantyx/` は変更不可、計器は完了したため）: (1) 主題の二重前置（上 T10）; (2) 回答 run が主題を知らず、融合 slot の記憶文に当たらない; (3) A1/A0 のターン注記付き値が生 hit を不一致にする; (4) 構造 arm では 12 回の tool 呼出で turn_limit になり report が無い turn が出る（A2b 23、A2 14）。
