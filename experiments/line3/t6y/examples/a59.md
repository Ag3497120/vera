# 例 a59: 彫師とは何ですか

- 問い: 彫師とは何ですか
- 正解（どれか一つが経路にあれば正解）: 職人、浮世絵版画、板木
- 項目数: 統合前 6、断面の割り当てだけ違うものを統合した後 **6**（このうち正解を含む項目 3）
- 表示: 全 6 項目（一覧の並びは読み出しの並び＝中心・経路の語順の辞書順）
- 各項目の「経路」: 断面ごとの経路の語を ／ でつないだもの。断面の割り当ては区別しないので、同じ経路が複数の断面にあれば ×回数 で示し、経路は並べ替えて ｜ で区切る。◎ = その項目の経路に正解の語を含む

| # | 参考の中心 | 経路（断面ごとの語） | 正解 |
|---|---|---|---|
| 1 | のこと | こす／起／のこと ×3 |  |
| 2 | のこと | ほりし／起／のこと ×3 |  |
| 3 | のこと | 彫師／起／のこと ×3 |  |
| 4 | のこと | 板木／起／のこと ×3 | ◎ |
| 5 | のこと | 浮世絵版画／起／のこと ×3 | ◎ |
| 6 | のこと | 職人／起／のこと ×3 | ◎ |

## 「似ている」の候補（どれを採るかは決めていません）

対象は上の表示項目（6 項目、15 組）。各項目の語 = 全断面の経路の語を集合にしたもの（助詞等は取り除き済み、順序は無視）。

### 尺度ごとの「似ている組」の数と、消した場合に残る項目数

消し方（尺度共通）: 一覧の並びの先頭から見て、すでに残した項目のどれかと「似ている」なら消す（先頭が残る）。部分集合の尺度だけは「語が他の項目の語に含まれる項目を消す（同じ集合なら後ろを消す）」。

| 尺度 | 似ている組 / 全15組（表示項目） | 消える項目 / 6（表示項目） | 消える項目 / 6（一覧全体） |
|---|---|---|---|
| (i) 語の集合が同じ（順序無視） | 0 | 0 | 0 |
| (iii) 中心が同じ | 15 | 5 | 5 |
| (v) 経路 1 本だけ違う（中心同じ、他の経路は同じ） | 0 | 0 | 0 |
| (iv) 一方の語がもう一方の語に含まれる | 0 | 0 | 0 |
| (ii) 語の重なり（Jaccard）≥ 1/2 | 15 | 5 | 5 |
| (ii) 語の重なり（Jaccard）≥ 2/3 | 0 | 0 | 0 |
| (ii) 語の重なり（Jaccard）≥ 3/4 | 0 | 0 | 0 |
| (ii) 語の重なり（Jaccard）≥ 9/10 | 0 | 0 | 0 |
| (ii) 語の重なり（Jaccard）≥ 1 | 0 | 0 | 0 |

### 例: 各尺度で「似ている」と出る組（表示項目の番号。最大 3 組）

- (i) 語の集合が同じ: 該当 0 組。例 なし
- (iii) 中心が同じ: 該当 15 組。例 #1 と #2、#1 と #3、#1 と #4
- (iv) 語が含まれる: 該当 0 組。例 なし
- (v) 経路 1 本だけ違う: 該当 0 組。例 なし
