## 「似ている」の候補（どれを採るかは決めていません）

対象は上の表示項目（30 項目、435 組）。各項目の語 = 全断面の経路の語を集合にしたもの（助詞等は取り除き済み、順序は無視）。

### 尺度ごとの「似ている組」の数と、消した場合に残る項目数

消し方（尺度共通）: 一覧の並びの先頭から見て、すでに残した項目のどれかと「似ている」なら消す（先頭が残る）。部分集合の尺度だけは「語が他の項目の語に含まれる項目を消す（同じ集合なら後ろを消す）」。

| 尺度 | 似ている組 / 全435組（表示項目） | 消える項目 / 30（表示項目） | 消える項目 / 130（一覧全体） |
|---|---|---|---|
| (i) 語の集合が同じ（順序無視） | 11 | 8 | 88 |
| (iii) 中心が同じ | 163 | 27 | 127 |
| (v) 経路 1 本だけ違う（中心同じ、他の経路は同じ） | 0 | 0 | 0 |
| (iv) 一方の語がもう一方の語に含まれる | 11 | 8 | 88 |
| (ii) 語の重なり（Jaccard）≥ 1/2 | 102 | 23 | 121 |
| (ii) 語の重なり（Jaccard）≥ 2/3 | 102 | 23 | 121 |
| (ii) 語の重なり（Jaccard）≥ 3/4 | 11 | 8 | 88 |
| (ii) 語の重なり（Jaccard）≥ 9/10 | 11 | 8 | 88 |

### 例: 各尺度で「似ている」と出る組（表示項目の番号。最大 3 組）

- (i) 語の集合が同じ: 該当 11 組。例 #1 と #5、#1 と #10、#1 と #14
- (iii) 中心が同じ: 該当 163 組。例 #1 と #5、#1 と #10、#1 と #14
- (iv) 語が含まれる: 該当 11 組。例 #1 と #5、#1 と #10、#1 と #14
- (v) 経路 1 本だけ違う: 該当 0 組。例 なし
