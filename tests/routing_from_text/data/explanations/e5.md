We run four agents.
Bramble is our default builder: anything that needs code written goes to Bramble unless noted below.
Tusk is slower than Bramble but far more careful, so large refactors go to Tusk instead.
Pike checks work. Use Pike for verification and for adversarial testing.
Never let Pike write production code.
Sedge (we also call it the quiet one) reads big files and answers closed questions.
Bramble and Tusk come from the same lab, Harrow; Pike and Sedge come from a different lab, Fenn.
Whoever verifies must not be from the same lab as whoever implemented.
At most two Bramble runs at a time.
