## 3. データモデル

### 3.1 段と単位（決定 2、I-01、I-22）

【決定 I-01】3 段: 内容の塊（RUN）・辞書の語（WORD）・1 文字（CHAR）。【決定 I-22】機能語と疑問語も空間に単位として載せる。

| 段 | 単位【推奨、N-15】 |
|---|---|
| RUN | `ja_content_runs` の内容の塊に加え、塊と塊の間の文字列（「は」「の」「にある」など）も単位にする |
| WORD | UniDic 短単位の全て（助詞・助動詞・疑問語を含む）。記号・補助記号（句読点・括弧）を入れるかは N-15 |
| CHAR | 文の全ての文字。記号を入れるかは N-15 |

段は混ぜない。各段が独立した空間を持つ（I-16）。問いも同じ切り方で切るので、「どこ」「誰」「何」も問いの単位になり、問いの十字の腕に付く（I-07）。

**予見される帰結（設計役の推論、測って確かめる）**: 「は」「の」のような機能語は、ほぼ全ての文に現れるので、初期の比率（§3.5）が最も高く、ほぼ全ての語と同じ文を共有する。§4.4 の歩きは比率の下がらない方へ進むので、機能語が中心に選ばれやすくなる可能性がある。これを抑える規則は 3 行目にも 26 点にも無いので、設計役は足さない。T13 で「中心が機能語になった答えの数」を数えて報告する。

### 3.2 規則化された構造（決定 3、I-02）

【決定 I-02】取り込み時に中心を決めない。段 t ごとに次を持つ【推奨の形】。

```
Space_t
  sentences : sid -> {text, source, units: [u1, u2, ...]}   # 文中の出現順
  postings  : u -> sorted [sid, ...]
  N         = 文の数
  n(u)      = |postings(u)|
  n(u,v)    = |postings(u) ∩ postings(v)|                    # 同じ文に書かれた数（辺の重み）
  p(u,v)    = u の初出が v の初出より前にある文の数             # 語順（L3-3、I-04）
```

整数のみ。n(u,v)・p(u,v) は posting の積集合から必要なときに正確に計算する（L-13）。全ての単位・辺は sid に戻れる。

### 3.3 十字（I-03）

【決定 I-03】中心＋6 腕×腕に沿って並ぶ席。

```
Cross
  center      : 単位
  arms[a][k]  : a ∈ (+x,-x,+y,-y,+z,-z), k = 0..L-1（k=0 が外端＝断面の側）
  orientation : g ∈ G24（立方体の 24 回転）
  辺          : arms[a][k]—arms[a][k+1]、arms[a][L-1]—center
```

腕の長さ L（容量 6L）は、【決定 I-18】「十字の要領についてももう一度しっかりと測り直す」に従い**固定しない**。測り方は N-09。測るまでの試験用の既定は L=4（L-04）。

### 3.4 配置と初期整合位置（決定 8、I-04、I-06）

【決定 I-04】配置の安定は「隣り合う語の共有＋語順」で測る。【決定 I-06】語に初期のエネルギー比率を与えて「初期整合位置」を決める。

各単位 c を中心とする十字 `DataCross_t(c)`（pool = c と同じ文に書かれた単位）を、次の辞書式の鍵で最も安定な配置にする。

1. 鍵 1（共有）: `-Σ_{十字の辺 (x,y)} n(x,y)`
2. 鍵 2（語順）: `-Σ_{腕の辺を外→内に読む (x→y)} p(x,y)`
3. 鍵 3（初期整合位置、N-02 の推奨 (a)）: 腕を外→中心へ読んだとき、初期の比率 r0 が下がる辺の数（少ないほど整合）。

動き・同点の扱い・安定の判定は第 1 版と同じ: 任意の 2 セル（pool の外の単位とも）の入れ替え、最急降下、最良の手が同点なら全ての枝、終点が回転の違いを除いて一つなら安定、複数か予算切れなら不安定（不安定は §5 の引き金）。

鍵 3 をどこに置くか（最優先か、3 番目か、配置に使わないか）は N-02。

### 3.5 語のエネルギー（決定 3・7、I-06）

【決定 I-06】初期の比率は「その語を含む文の数の割合」:

```
r0_t(v) = n(v) / N          # 正確な分数
```

これが「初期整合位置」の下地で、問いはこの下地からエネルギーを変える。**問いによる変化の式はオーナーの答えに無い**ので N-01。推奨 (a):

```
E_Q(v) = ( n(v) + Σ_{q∈Q} n(q,v) ) / N     # 問い全体による比率
E_q(v) = ( n(v) + n(q,v) ) / N              # 問い語 q 一つによる比率（その語が付いた断面が使う）
```

問いが無ければ E = r0 に戻る。問い語と同じ文に書かれた語だけが、その文の数だけ上がる。

### 3.6 例（機能語を省いた説明用）

文「遊眠（ゆうみん）は日本の漫画家。」の内容の塊 `遊眠, 日本, 漫画家` だけで説明する（**I-22 により実際の空間には「は」「の」も載る。機能語を含む例の正しい値は T3 のコードで計算して試験に固定する**）。N=1、n は全て 1、r0 は全て 1。`DataCross(遊眠)` の配置: 鎖 [日本, 漫画家]→遊眠 は鍵 1 = −2、鍵 2 = −1。星と逆順の鎖は鍵 1 = −2、鍵 2 = 0。鍵 3 は全て 0（r0 が等しい）。→ 鎖 [日本, 漫画家] が一意に最小で、安定。

## 4. 問いの周期

### 4.1 問いの投入（決定 3、I-07）

【決定 I-07】語順どおり 6 本の腕の外端に。問いを段 t で切った単位 q1, q2, … を世界の方向 AXES[1..6] の外端に付ける。I-22 により疑問語・機能語も単位なので、付く数は第 1 版より増える。7 個目以降は外端に付けず E_Q だけに入れる【推奨、N-21】。付いた断面は E_{q_s} で、付いていない断面は E_Q で読む【推奨、第 1 版のまま】。

### 4.2 空間全体を読む（I-08）

【決定 I-08】「毎回、空間全体だが、立体十字構造で高速化できるかもしれない」。

**全体読み（基準の定義）**: 問いごとに、段 t の全ての単位 c について `DataCross_t(c)` に問いの十字を投入し、§4.4〜§4.6 の周期を回す。全ての十字の結果を集め、§4.7 と §4.9 で比べる。上の層があれば上の層も同じく全体を読む（§5）。

**答えの接地**: 全体読みでは、問いと関係の無い十字も初期整合位置のまま「一致」しうる。問いの無いところで答えを作らないため、答えには「働く断面（§4.4）のうち問い語が付いたものが 1 つ以上」を求める【推奨、N-03】。これは 3 行目の「一番端に足されるクエリ…によって推論する」の推奨の読みで、オーナーの答えには無い。

**構造による高速化（全体読みと同じ結果を返すと示せるものだけ）**: N-03 (a) のもとでは、付いた断面が働くには、問い語→外端の最初の席の辺が実証されていること（n(q, 席の語) > 0）が要る。十字の中の動きは十字の中の単位しか動かさない（N-04 (a)）。よって「問い語のどれとも同じ文に書かれた単位を一つも持たない十字」は、どう動かしても答えにならない。高速化はこの十字を飛ばすことだけとし、**飛ばした版と全体読みの出力が byte 一致することを試験する**（T5b）。

- 注意 (I): I-22 により「は」「の」がほぼ全ての十字に載るので、この高速化はほとんど何も飛ばさない可能性がある。それでも結果の同値を壊す近道（上位 K 個だけ読むなど）は使わない。
- 全体読みが大きなデータで時間内に終わらないとき、打ち切りや近似はしない。時間を報告してオーナーに上げる（N-18）。
- 上の層の木を降りて読む範囲を絞る形の高速化は、全体読みと一致を試験で示せたときだけ使える（N-04, T5b）。

### 4.3 断面（決定 4、I-09）

【決定 I-09】今の窓のまま。世界に固定した 6 方向の断面に、現行 `visible_axes` の環状 window=1 を当てる。十字の向き g が回ると、各断面の前に来る腕が変わる。

### 4.4 3 つの比率と一致（決定 7、I-10、I-11）

【決定 I-10】3 つを別の量にする。【決定 I-11】3 つとも同じ 1 語を指す。式は第 1 版の推奨を、§3.5 のエネルギーに置き換えたもの:

- **R1 断面の中**: 断面 s は前の腕を外端から中心へ歩く。辺が実証され（n(x,y) > 0）、次の席のエネルギーが下がらない（E_s(次) ≥ E_s(今)）間は進む。止まった単位（中心に着けば中心）が d_s。歩けた断面を働く断面とよぶ。
- **R2 辺を伝った時**: `F(v) = Σ_{u は v の十字上の隣} E_Q(u)·n(u,v)/n(u)` の最大が一つならその単位。
- **R3 配置そのもの**: `B(v) = Σ_{u は v の十字上の隣} n(u,v)/n(v)`（問いに依らない）の最大が一つならその単位。
- **一致**: 働く断面が 1 つ以上（うち問い語の付いたものが 1 つ以上、N-03）、全ての d_s・R2・R3 が同じ単位 d。最大が複数の比率は「指さない」。

### 4.5 動き（決定 5、I-12）

- 回転: 立方体の 24 回転（恒等以外 23）。面の入れ替え: 十字の任意の 2 席の交換（中心を含む）。動きは十字の中だけ（N-04 推奨 (a)）。
- 【決定 I-12】順に比べる: (1) 指す先の種類数 − 1、(2) −働く断面の数、(3) −F(d*) の辞書式で厳密に良くなる手だけ受理。
- 最良の手が同点なら全ての枝を辿る（上限 L-05。上限に当たった件数を報告）。

### 4.6 停止（決定 6、I-05）

【決定 I-05】どの 1 手も改善しない＋一致。停止はどの 1 手も鍵を厳密に良くしない状態。答えるのは、そこで §4.4 の一致が成り立つとき。escape は使わない。安定度（I-15）は、1 手動かしても指す中心 d が変わらない手の割合 inv（正確な分数）。

### 4.7 文の候補・採用か一覧（決定 7、I-13、I-14、I-15）

【決定 I-13】「並べ方すべてが候補」。【決定 I-14】一番安定な候補が 1 つなら採用、同点なら一覧。【決定 I-15】安定度は動かしても変わらない手の割合。

1. 一致した不動点ごとに、働く断面 s の phrase_s（外→中心の語、最後に d）を作る。
2. **並べ方すべて**: 何を並べ替えるかは N-13。推奨 (a) は phrase を塊として並べ替えること（働く断面が k 本なら k! 通り、最大 6! = 720）。語を一つずつ全て並べ替える (b) では、席が 6L+1 = 25 個のとき最大 25! 通りになり、列挙できない。
3. 候補の安定度: I-15 のとおり、その候補を生んだ状態の inv。
4. 全ての十字・枝・段の候補を集め、安定度の最大が一つなら `ANSWER`、複数なら `CHOICE`（一覧）。
5. **予見される帰結（必ずオーナーに伝える、N-14）**: 一つの状態から生まれた並べ方は、全て同じ inv を持つ。したがって働く断面が 2 本以上ある答えは、決定 I-13〜I-15 をそのまま組むと**必ず同点になり、一覧（CHOICE）になる**。採点（§7.2）では CHOICE は棄権に数えるので、複数の断面を持つ答えは全て棄権に数えられる。並べ方ごとの安定度を別に定めるか、このまま一覧にするかは N-14。本版は答えのとおり一覧にする。
6. 件数を黙って打ち切らない。各問いで、候補の総数・一覧の件数を出力と報告に必ず出す。一覧の表示に上限を設けるかは N-20（上限を設けても総数は出す）。
7. 全ての出力語に痕跡 {段, 層, 十字, 腕, k, 単位, 単位を含む sid, 経路の各辺を実証する sid, スナップショット id（N-10）}。

### 4.8 型付きの判定

| 判定 | 意味 |
|---|---|
| ANSWER | 安定度の最大の候補が一つ |
| CHOICE | 安定度の最大の候補が複数（一覧）。採点では棄権 |
| AMBIGUOUS | 違う中心を指す一致が同じ安定度で複数（CHOICE の一種として一覧も出す） |
| UNKNOWN_NO_EVIDENCE | 問い語の付いた働く断面が、どの十字でも 0 |
| UNKNOWN_SECTION_DISAGREEMENT | 不動点で断面どうしが割れた |
| UNKNOWN_RATIO_DISAGREEMENT | 断面は一致したが R1・R2・R3 が割れた |
| UNKNOWN_NO_FIXED_POINT | 予算内に不動点に着かない |
| UNKNOWN_UNSTABLE_PLACEMENT | 問いの最中に配置の安定が失われ、まだ重ねられていない（N-11） |
| UNKNOWN_FULL_READ_TIMEOUT | 全体読みが時間内に終わらない（N-18。打ち切った結果は出さない） |

### 4.9 段（I-16、I-25）

問い「遊眠とは何ですか」の内容の塊 [遊眠] を +x に付ける。E は全て 2（n=1、N=1、全ての語が遊眠と同じ文）。鎖のままでは R1→遊眠、R2→漫画家（F=4 対 2）、R3→漫画家（B=2 対 1）で割れる。日本か漫画家を別の腕に動かした星形では R1・R2（F(遊眠)=4）・R3（B(遊眠)=2）とも遊眠で一致し、働く断面は 2 本。phrase は「日本 遊眠」と「漫画家 遊眠」。I-13 により並べ方 2 通りが候補になり、同じ inv なので CHOICE（一覧 2 件）になる（§4.7 の 5 の帰結の実例）。

## 5. 入れ子・待機中の最適化・記憶（決定 9、L3-10、I-18、I-19、I-20、I-24）

### 5.1 層の形（I-19）

【決定 I-19】「下の層のものを多数持って内部に安定状態を多数持つ形で…それぞれを大きな立体十字構造として並べて…多数の安定状態で比較して…十字の量がいっぱいだとどんどん上に重ねていく。十字が宇宙」。

【推奨の形】
- 第 h+1 層の要素は、第 h 層の十字の**安定状態**一つ一つ（一つの十字が複数の安定状態を持てば、その数だけ要素になる。「安定状態のそれぞれでの構成で」）。
- 第 h+1 層の十字（大きな立体十字）は、§3.3 と同じ形で、席に第 h 層の要素を載せる。並べ方は §3.4 と同じ鍵で決める。そのための量（要素の n・同じ文の数・語順・初期の比率）の定義は N-05。推奨: 要素の posting ＝ その安定状態に載った単位の posting の和集合。そうすれば §3 の式がそのまま再帰的に使える。
- どの要素が上に上がるか（全ての十字か、安定を失ったものだけか）、「いっぱい」とは何か（測り直した容量に達したときか、配置が不安定になったときか）は N-06。
- 内部の多数の安定状態の比較は、その層で §4 の周期を回すことで行う【推奨、N-07】。
- 最上層は一つの十字（「十字が宇宙」）。

### 5.2 重ねる時機（決定 9、I-18）

【決定 I-18】に含まれる 4 つの動き（監査役の読みの (a)〜(d) に対応させる。対応づけは監査役と設計役の解釈）:

1. **問いの最中**: 周期の中で配置の安定が失われた（同点の終点が複数・予算切れ）とき。その問いをどう扱うか（その場で重ねて読み直すか、型付きで返して後で重ねるか）は N-11。推奨: `UNKNOWN_UNSTABLE_PLACEMENT` を返し、重ねる作業を待機中の最適化に渡す（一つの問いの答えを決定論に保つため）。
2. **待機中の最適化（新しい部品）**: 問いの前・問いの無いときに、空間の全ての十字と各層について安定状態を探し、配置を最適化し、必要を見つけたら自動で重ねる。起動の条件・順番・止める条件は N-08。推奨: 呼ばれたとき（CLI・問いの無いとき）に、決まった順に全十字を回り、一巡して何も変わらなければ止まる（全体の不動点）。予算を超えたら途中のスナップショットを残して止まる。
3. **容量の測り直し**: 以前の「24 語」を前提にしない。測り方は N-09。推奨: 腕の長さ L を変えて、配置が安定でいられる最大の詰め具合（L ごとの不安定な配置の率）を測る。8 月の「経路選択の正答」による測り方も並べて報告する。L の既定はその結果でオーナーが決める。
4. **下の層の読み直しの繰り返し**: 上の層の周期が下の層の要素を指したら、その要素の十字で下の層の周期を回し直し、それで上の層を回し直す、を繰り返す。止める条件は N-12。推奨: 全ての層で指す先が変わらなくなったら止める。予算を超えたら `UNKNOWN_NO_FIXED_POINT`。

### 5.3 決定論とスナップショット（N-10）

待機中の最適化で配置が時間とともに変わるので、同じ問いの答えも変わりうる。推奨: 最適化の結果は番号つきのスナップショットとして保存し、問いは指定したスナップショットに対して回す。答えにスナップショットの番号を記録する。同じスナップショットと同じ問いなら同じ答え（決定論）。常に最新の配置を使う（答えが時とともに変わることを許す）か、は N-10。

### 5.4 層の間の受け渡し（L3-10、I-20）

【決定 I-20】両方組んで測る。第一層の答え（中心と読み出した語）を次の層の問いの十字として投入する。A: 初期の問い＋前の層の答え、B: 前の層の答えだけ。現行の C（主辞だけ）は比較用。上の層の読み出し（要素は十字なので、語として何を出すか）は N-19。推奨: 経路上の要素について、その要素（安定状態）の読み出しをつなげる。痕跡は下の層まで辿れる。

### 5.5 ロック（I-23）

【決定 I-23】今回は組まない。

### 5.6 記憶（I-24）

【決定 I-24】「10 月の決定どおり別の層に」。【推奨の形】記憶は、基盤の空間とは別の空間（同じ §3 の形）として持ち、10 月の記憶のソブリン（W4-m、`sovereign.py`、F15。追記専用・切り離し可能）を出どころにする。切り離すと、その空間は読まれない。
- 問いのときに記憶の層をどう読むか（基盤と同じ周期で並べて比べるか、など）は N-16。推奨: 毎回、基盤の各段と同じく別に周期を回し、§4.9 と同じく安定度で並べて比べる。答えの痕跡に「記憶由来」と出す。
- 何を記憶に書くか（利用者の発話・採用された答え・人が確認したものだけ、など）は N-17。設計役は推奨を置かない（10 月の決定の範囲を設計役は確認しきれていない）。

答えた＝ANSWER*／REVERSE_*／SEEDED／L3 の ANSWER。それ以外（CHOICE・AMBIGUOUS・UNKNOWN_*）は棄権で、誤答に数えない。正答＝答えた ∧ 正解の語が文に含まれる ∧ 中心（核）が主題の部分文字列。誤答＝答えたが正答でない、または答えられない問いに答えた。

### 7.3 データ量の曲線

7 条件 × 全ての系。予想は書かない。

### 7.4 痕跡
