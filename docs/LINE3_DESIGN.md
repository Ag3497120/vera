## 3. データモデル

### 3.1 段と単位（決定 2、I-01、I-22、N-15）

【決定】3 段: 内容の塊（RUN）・辞書の語（WORD）・1 文字（CHAR）。すべての段に助詞（機能語・疑問語）を載せ、句読点は載せない。

| 段 | 単位 |
|---|---|
| RUN | `ja_content_runs` の内容の塊＋塊と塊の間の文字列（「は」「の」「にある」など）。句読点・記号は除く |
| WORD | UniDic 短単位の全て（助詞・助動詞・疑問語を含む）。補助記号・記号は除く |
| CHAR | 文の全ての文字。句読点・記号は除く |

句読点・記号の判定は L-03（UniDic の品詞の「補助記号」「記号」、文字は Unicode の P*・S* 類。括弧の中の読み仮名は文字として残る）。段は混ぜない。問いも同じ切り方で切る。
助詞が中心・答えになりやすい点は【決定】「そのまま組んで測る」。抑える規則は足さない。

### 3.2 規則化された構造（決定 3、I-02）

段 t ごとに（取り込み時に中心を決めない）:

```
Space_t
  sentences : sid -> {text, source, kind, units: [u1, u2, ...]}   # 出現順。kind は L-19
  postings  : u -> sorted [sid, ...]
  N         = 文の数
  n(u), n(u,v) = |postings ∩|, p(u,v) = u の初出が v より前の文の数
```

整数のみ。n(u,v)・p(u,v) は posting の積集合から必要なときに計算（L-13）。記憶の層（§5.6）も同じ形の空間なので、文を後から追記できること・文の種類（基盤／問い／答え／利用者の文）を持てることが要る（**T1 への影響、§9 末尾**）。

### 3.3 十字（I-03、N-09）

```
Cross: center, arms[a][k]（a ∈ AXES, k=0 が外端）, orientation g ∈ G24
辺: arms[a][k]—arms[a][k+1], arms[a][last]—center
```

【決定 N-09】容量は「エネルギーの安定だけで自動で決める」。腕の長さは固定の値を持たない。十字に単位を足していき、配置の安定が崩れる直前の大きさが、その十字の容量になる（§5.1）。実装上は T2 の一様な腕の長さ L を、必要に応じて L+1 の十字に作り直す形でよい（L-04）。

### 3.4 初期の並び（決定 8、I-04、I-06、N-02）

【決定 N-02】「最初の並びのエネルギーは安定したものを人為的に組んで、そこからそのエネルギー比率がどうなるかを観察してみる」。

- 安定の判定は【決定 I-04】の鍵: 鍵 1 共有 `-Σ_{辺} n(x,y)`、鍵 2 語順 `-Σ_{外→内の辺} p(x,y)` の辞書式。どの 1 手（2 席の入れ替え、pool の外の単位とも）も鍵を良くしない状態が安定。最良の手が同点なら全ての枝を辿り、終点が回転の違いを除いて一つなら安定、複数なら不安定。
- 初期の比率 r0 は位置の鍵には使わない（第 2 版の推奨 (a) の鍵 3 は廃止）。r0 は「下地」のエネルギーで、問いによってそこからどう変わるかを観察する。
- **観察**: 問いのたびに、読んだ十字の各単位について r0 と問いの後のエネルギー E、その比を記録する観察記録を残す（L-20）。
- 「人為的に組む」の具体的な手順（安定を探索で見つけるのか、決まった規則で組むのか）は **M-1(a)**。

### 3.5 語のエネルギー（決定 3・7、I-06、N-01）

```
r0_t(v)  = n(v) / N                                  # 【決定 I-06】
E_Q(v)   = r0(v) + Σ_{q∈Q} n(q,v) / N                 # 【決定 N-01】問いの語と共有する文の割合を足す
E_q(v)   = r0(v) + n(q,v) / N                          # 問い語一つ（その語が付いた断面が使う）
```

全て `Fraction`。問いが無ければ E = r0。

## 4. 問いの周期

### 4.1 問いの十字（I-07、N-21）

【決定 I-07】問いの単位を語順どおり 6 本の腕の外端に付ける。【決定 N-21】「問いも十字として入れ子にする」: 7 個目以降の単位は、問いの十字を入れ子にして持つ。入れ子の問いの十字をどこに投入するかは **M-5**。付いた断面は E_{q_s} で、付いていない断面は E_Q で読む。

### 4.2 読む範囲（I-08、N-04、N-18）

【決定 I-08】毎回、空間全体。【決定 N-04】動きは十字の中だけ。高速化は「問い語のどれとも同じ文に書かれた単位を一つも持たない十字を飛ばす」ことで、全体読みと byte 一致を試験する。
【決定 N-18】「推論の量で調整する方向で進める。立体十字による探索の高速化もできるかが焦点」。

- 全体読み: 段 t の全ての単位 c の十字（と上の層）に問いを投入し、§4.4〜§4.6 を回す。
- **推論の量**: 一つの問いで行う推論の量を調整できるようにする。量が全体に満たないとき何を先に読むか、量を何で数えるかは **M-2**。量を減らしたときは、読んだ十字の数・読まなかった十字の数を出力に必ず出し、「部分読み」と印を付ける。
- 構造による高速化は研究の焦点として別チケット（T5c）にする。全体読みと同じ結果を返すと試験で示せたものだけを既定にできる。

### 4.3 断面（決定 4、I-09）

世界に固定した 6 方向の断面、現行の環状 window=1。十字の向きが回ると前に来る腕が変わる。

### 4.4 3 つの比率と一致（決定 7、I-10、I-11、N-03）

- R1 断面の中: 外端から中心へ、辺が実証され（n>0）E_s が下がらない間は進む。止まった単位（中心に着けば中心）が d_s。
- R2 辺を伝った時: `F(v) = Σ_{u は隣} E_Q(u)·n(u,v)/n(u)` の最大が一つならその単位。
- R3 配置そのもの: `B(v) = Σ_{u は隣} n(u,v)/n(v)` の最大が一つならその単位。
- 一致: 【決定 N-03】問いの語が付いた断面が 1 つ以上働き、全ての d_s・R2・R3 が同じ 1 語。最大が複数の比率は指さない。

### 4.5 動き（決定 5、I-12、N-04）

24 回転（恒等以外 23）＋十字の中の 2 席の入れ替え（中心を含む）。(1) 指す先の種類数 − 1、(2) −働く断面の数、(3) −F(d*) の辞書式で厳密に良くなる手だけ受理。最良の手が同点なら全ての枝。

### 4.6 停止（決定 6、I-05）

どの 1 手も改善しない不動点で、一致していれば答える。安定度 inv = 1 手動かしても指す中心が変わらない手の割合。

### 4.7 文の候補・採用か一覧（I-13、I-14、I-15、N-13、N-14、N-20）

- 【決定 N-13】並べ替えは断面の経路ごと: 働く断面が k 本なら k! 通り（最大 720）。
- 安定度は候補を生んだ状態の inv。最大が一つなら ANSWER、複数なら CHOICE（一覧）。
- 【決定 N-14】並べ方の候補が同点になって一覧になる点は「そのまま組んで影響を見る」。
- 【決定 N-20】一覧に上限を設けない。数が多すぎたらオーナーに示す。利用者にどれが一番回答として合っているかを選んでもらい、それを次の最適化に繋げる。「多すぎ」の目安は表示のための値で、出力される件数は変えない（L-21）。選択を次の最適化にどう繋げるかは **M-4**。
- 痕跡: {段, 層, 十字, 腕, k, 単位, sid, 経路の辺を実証する sid, 状態の版（L-22）}。

### 4.8 型付きの判定

ANSWER／CHOICE／AMBIGUOUS／UNKNOWN_NO_EVIDENCE／UNKNOWN_SECTION_DISAGREEMENT／UNKNOWN_RATIO_DISAGREEMENT／UNKNOWN_NO_FIXED_POINT。部分読み（M-2）のときは判定に `partial_read: {read, unread}` を添える。第 2 版の UNKNOWN_UNSTABLE_PLACEMENT は、N-11（その場で重ねて続ける）により「上の層を作り終えても上でも安定しない」場合だけに残る。UNKNOWN_FULL_READ_TIMEOUT は N-18 により廃止。

### 4.9 段・追加の検査

【決定 I-16・I-25】各段を別に全て回し、一番安定なもの。【決定 I-17】追加の検査は入れない。

## 5. 入れ子・確認と最適化・記憶

### 5.1 積み上げ（決定 9、I-18、I-19、N-05、N-06、N-07、N-09）

オーナーの答えを合わせると、次の手順になる（つなぎ方の細部は設計役の読みで、意味に関わる残りは M-1）:

1. 十字に単位を足していく（足す順は M-1(b)）。足すたびに §3.4 の安定を判定する。
2. 【決定 N-05】足したことで安定が保てなくなったら、**その直前に安定していた状態を復元して採用する**。それがその十字の容量（【決定 N-09】）。
3. 【決定 N-07】安定が崩れたら、それまでで一番大きかった（＝崩れる直前の）安定状態が、大きな立体十字構造に束ねられ、新たな大きな空間ができる。そこでは崩れる前の状態が横に並んでいく。
4. 【決定 N-06】すべての安定状態を上げる。大きな十字は容量か不安定で満ちる。満ちそうになると、それも大きな立体十字に束ねられる。これを繰り返す。【決定 I-19】「十字が宇宙」。
5. 【決定 N-07】これにより「安定度は自動で見極められる」: 上の層での比較はこの束ね方そのもので行う。
6. 上の層の要素（束ねられた安定状態）を上の十字の席に並べる量と並べ方は M-1(c)。

### 5.2 いつ確認・最適化・積み上げをするか（I-18、N-08、N-11）

- 【決定 N-08】常駐の待機処理ではなく、**聞かれた際に**確認と最適化が起きる。新たな段を作るか十字に詰めるかの選択で待ち時間が増えうるので、内部状態を把握して UI などに表示する仕組みを持つ（L-23: 内部状態の出力の形。T10）。
- 【決定 N-11】問いの最中に安定が崩れたら、その場で重ねて、上の層で続けて答える。
- これにより、空間の状態（配置・層）は問いを重ねるにつれて変わる。状態は永続化し、版を持つ（L-22）。

### 5.3 表示の分離（N-10）

【決定 N-10】最適化で答えが変わる点は「思考過程として表示するなどして表示を分ける」。出力を `answer`（判定・文・痕跡）と `thought`（その問いの間に起きた確認・最適化・積み上げ・観察記録・状態の版の移り）に分ける（L-23）。
評価の決定論: 同じ初期の空間から同じ問いの列を同じ順に与えれば、同じ出力の列になる（再生の試験）。

### 5.4 層の間（L3-10、I-20、N-12、N-19）

第一層の答えを次の層へ流す。【決定 I-20】A（初期の問い＋前の層の答え）と B（前の層の答えだけ）の両方を組んで測る。【決定 N-12】下の層の読み直しを繰り返し、どの層も変わらなくなったら止まる（予算超えは UNKNOWN_NO_FIXED_POINT）。【決定 N-19】上の層の読み出しは、経路上の要素（下の十字）の読み出しをつなげる。痕跡は下の層まで辿れる。

### 5.5 ロック

【決定 I-23】今回は組まない。

### 5.6 記憶（I-24、N-16、N-17）

- 【決定 I-24】10 月の決定どおり別の層（記憶のソブリン、切り離せる）。
- 【決定 N-16】毎回、別の空間として読み、安定度で比べる。
- 【決定 N-17】記憶に書くもの: 「問いと採用した答え」「利用者の文（会話）」「探索の状態」。問い・答え・利用者の文は文として記憶の空間（§3.2 の形、kind で区別）に追記する。「探索の状態」の持ち方と、それを次の問いで使うかは **M-3**。
- 記憶の出どころは `verantyx/sovereign.py` の W4-m（追記専用）。line3 側は読むだけで、そのファイルを変えない。
