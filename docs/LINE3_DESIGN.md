## 3. データモデル（決定 2・3・8）【全て推奨】

### 3.1 単位と段（決定 2「複数の粒度を段に並べる」）

【推奨】段を 3 つ持つ（I-01）。

| 段 | 単位の切り方 | 既存の部品 |
|---|---|---|
| RUN | `lang.ja_content_runs`（文字種の連。8 月の取り込みと同じ） | `lang.py:260` |
| WORD | UniDic 短単位のうち内容語（名詞・動詞・形容詞・形状詞）。機能語を入れるかは I-22 | fugashi（F13: 稀な名前で誤りあり） |
| CHAR | RUN の単位を 1 字ずつ | 無し（自明） |

段は互いに混ぜない。各段は独立した空間を持つ（段の統合は §4.9、I-16）。8 月の測定（vera1.txt L531, L549-556 (C)）で、区切り違いを一つの選挙に合算すると蔵書外の誤答が 0→8 に増えたことに合わせた推奨。

### 3.2 規則化された構造（決定 3「データを入れることで規則化されたもの」）

【推奨】段 t ごとに、取り込んだ人の文から次を作る。**取り込み時に「核」を規則で選ばない**（中心は探索で決まる。L3-6・L3-8 の読み。I-02）。

```
Space_t
  sentences : sid -> {text, source, units: [u1, u2, ...]}   # 文中の出現順（段 t の単位列）
  postings  : u -> sorted [sid, ...]                         # u を含む文
  n(u)      = |postings(u)|                                  # 語のデータ上のエネルギー（E0、I-06）
  n(u,v)    = |postings(u) ∩ postings(v)|                    # 同じ文に書かれた回数（辺の重み、I-10）
  p(u,v)    = 文のうち u の初出が v の初出より前にある数        # 読む順番（L3-3）
```

- 全て整数。n(u,v) と p(u,v) は posting の積集合から必要なときに正確に計算する（L-13）。
- 出典: 全ての単位・全ての辺は、それを含む文の sid に戻れる（§7.4 の追跡試験の土台）。
- 現行の `CrossStore` は「核→facet→count」の星形で、核の選択が入っている（F9）。line3 の空間はその一般化（全ての対を持つ）で、`CrossStore` は基準線のために残す。

### 3.3 十字の幾何（I-03）

【推奨】`LinearCross` を土台にした「中心＋6 腕×L セル」の十字（L=4、容量 24 セル＋中心。8 月の「1 ノード＝6×4＝24 語」(C L69-83) と同じ容量。L-04）。

```
Cross
  center      : 単位 1 つ
  arms[a][k]  : a ∈ AXES = (+x,-x,+y,-y,+z,-z), k = 0..L-1（k=0 が外端＝断面の側、k=L-1 が中心の隣）
  orientation : g ∈ G24（十字の向き。世界に固定した 6 方向へ、どの腕が向いているか）
十字の辺（決定 7 の「辺」の推奨、I-10）:
  arms[a][k] — arms[a][k+1]、arms[a][L-1] — center
```

- 断面は世界に固定した 6 方向にある（決定 4「腕からの視点」）。十字が回ると、各断面の前に来る腕が変わる。
- 空のセルは読みで飛ばす。詰め方は中心側に詰める（L-09）。
- 現行の `ShellCross`（腕先端＋4 側面、読む順 tip→N→S→E→W）を残す案は I-03 の選択肢 (b)。

### 3.4 配置（決定 8「エネルギーが安定する配置」）

【推奨】中心にする単位 c ごとに、その十字 `DataCross_t(c)` を建てる。中身は c と同じ文に書かれた単位の集まり（pool）。配置は次の手順で決める（I-04, I-05）。

1. 配置のエネルギー（小さいほど安定）。重みつき和を作らず、2 つの鍵の辞書式で比べる:
   - 鍵 1（結びつき）: `-Σ_{十字の辺 (x,y)} n(x,y)`
   - 鍵 2（読む順番、L3-3）: `-Σ_{腕の辺を外→内に読む (x→y)} p(x,y)`（中心の隣→中心の辺を含む）
2. 動き: 任意の 2 セル（中心を除く。pool のうち十字に載っていない単位とも）の入れ替え。
3. 最急降下。最良の動きが同点で複数あれば、全ての枝を辿る（上限 L-05）。
4. 終点が「回転で重なる違い」を除いて一つだけなら**安定**。終点が複数（同じエネルギーで中身の違う配置）か、予算内に不動点が無ければ**不安定**。不安定は決定 9 の引き金になる（§5）。
5. 決定論: 同じ空間からは同じ配置。計算は問いの時に必要な十字だけ行い、結果をキャッシュしてよい（建てる時に全部計算した場合と一致することを試験する。L-07）。

pool が容量を超えるとき（大きな語）、どれを載せるかもエネルギーで決まる。境目で同点になれば、それも不安定に数える（L-08）。

### 3.5 語のエネルギー（決定 3・7「言葉にエネルギーを持たせる」「クエリでエネルギーが変わる」）

【推奨】（I-06）

```
E0(v)   = n(v)                                   # データが与えるエネルギー
ρ_Q(v)  = Σ_{q∈Q} n(q,v) / n(v)                   # 問い Q が活性化したエネルギーの比率（正確な分数）
ρ_q(v)  = n(q,v) / n(v)                           # 一つの問い語 q による比率
```

- 全て `fractions.Fraction`。浮動小数点は判定に使わない（L-02）。同点は正確に判定できる。
- 問いが空間に投入されると、問い語と同じ文に書かれた語のエネルギー比率が上がる。これが「エネルギー比率が変わる」の推奨の読み。

### 3.6 例（1 文だけの空間）

文「遊眠（ゆうみん）は日本の漫画家。」。RUN 段の単位は `遊眠, 日本, 漫画家`（F13 の環境で確認 (O)）。n は全て 1、n(u,v) も全て 1、p は 遊眠<日本<漫画家。

`DataCross(遊眠)` の配置: pool = {日本, 漫画家}。
- 鎖 [日本, 漫画家]→遊眠: 鍵 1 = −2、鍵 2 = −(p(日本,漫画家)=1 + p(漫画家,遊眠)=0) = −1
- 星（日本・漫画家を別の腕に）: 鍵 1 = −2、鍵 2 = 0
- 鎖 [漫画家, 日本]→遊眠: 鍵 1 = −2、鍵 2 = 0
→ 鎖 [日本, 漫画家] が一意の最小で、**安定**。読む順番の鍵が無ければ 3 つが同点になり不安定になる（鍵 2 の効き）。

## 4. 問いの周期（決定 3・4・5・6・7）【全て推奨】

### 4.1 問いの十字と投入（I-07）

1. 問いを段 t の単位に切る: Q_t = [q1, q2, …]（問いの中の順）。
2. 問いの十字: q_i を世界の方向 AXES[i] の外端に付ける（i < 6）。7 個目以降は外端に付けず、ρ_Q にだけ入る（I-07）。
3. 断面 s に問い語が付いていれば「付いた断面」。付いた断面は自分の語 q_s の比率 ρ_{q_s} で読み、付いていない断面は問い全体の ρ_Q で読む。
4. 十字の向き g を回すと、どの腕がどの問い語の前に来るかが変わる。これで回転が意味を持つ（現行は F2 のとおり回転が効かない）。

### 4.2 空間のどこを読むか（I-08）

【推奨】問い語が中心にある十字、または問い語を腕に持つ十字を候補の中心 c とする。候補は `Σ_q n(q,c)/n(c)` の降順に並べ、上位 K=6（現行の腕の数、L-12）を取る。境目の同点は全て含める（同点を切らない）。含めた結果が上限 24 を超えたら `UNKNOWN_TOO_MANY_CANDIDATES`。
L3-12「推論のたびに全ノードを整列」を字義どおりに全空間で行う案は I-08 の (c)。

### 4.3 断面（決定 4「腕からの視点（現行）」、I-09）

【推奨】断面は世界に固定した 6 方向。視野は現行の `visible_axes` と同じ規則（環状 window=1）を世界の方向に当てる。断面 s は、自分の前に来ている腕の外端から中に入る。
現行の環状の隣（+x の隣が −z と −x）は AXES の並びで決まっていて立体の隣ではない。立体の隣（自分＋直交 4 方向、対極は見えない）にする案は I-09 (b)。対極を見るかどうかは L3-5「両方から攻める」と関わる。

### 4.4 3 つのエネルギー比率と一致（決定 7、I-10, I-11）

状態 σ =（十字の配置、向き g、付いた問い語）について:

- **R1 断面の中**: 断面 s は前の腕を外端から中心へ歩く。次のセルへ進むには、その辺が文で実証されていること（n(x,y) > 0。問い語→最初のセルも同じ）、かつ次のセルの比率が下がらないこと（ρ_s(次) ≥ ρ_s(今)）。比率が厳密に下がるか辺が切れたところで止まる。止まった単位、または中心に着いたら中心が、断面 s の指す中心 d_s。歩けた断面を「働く断面」と呼ぶ。
  - 比率が等しいとき中へ進むのは、方向が 3 行目の「断面から中心に向かって」で与えられているから。順序による同点崩しではない。
- **R2 辺を伝った時**: 単位 v に十字の辺から流れ込む量 `F(v) = Σ_{u は v の十字上の隣} ρ_Q(u) · n(u,v)/n(u)`。最大が一つなら、その単位が R2 の指す中心。
- **R3 配置そのもの**: 配置が v をどれだけ結びつけているか `B(v) = Σ_{u は v の十字上の隣} n(u,v)/n(v)`（問いに依らない）。最大が一つなら、その単位が R3 の指す中心。
- **一致**: 働く断面が 1 つ以上あり、全ての d_s が同じ単位 d で、R2 と R3 も d を指すとき。どれかが同点（最大が複数）なら、その比率は「指さない」とし、一致しない。

3 つの式は全て【推奨】で、オーナーの式ではない。§3.6 の例の続きで動き方を示す（§4.11）。

### 4.5 動き（決定 5「両方」）

- **回転**: 立方体の 24 回転の群 G24（3×3 の符号つき置換行列で行列式 +1。6 方向の置換として 24 個全て異なり、全て対極の組を保つ (O `design/rot24.py`)）。恒等以外の 23 個。
- **面の入れ替え**: 十字の任意の 2 セルの中身の交換（中心を含む。中心と腕のセルを入れ替えると、中心が別の語に移る）。
- 探索の向き（I-12）: 次の鍵を辞書式に小さくする動きだけを受理する（重みつき和にしない。現行 `Metrics.key` と同じ流儀）。
  1. 指す中心の種類数 − 1（R1 の各断面・R2・R3 の指す先。「指さない」も 1 種類と数える）
  2. −（働く断面の数）
  3. −F(d*)（d* は R2 の指す単位）
- 最良の動きが同点で複数あるときは全ての枝を辿る（上限 L-05）。順序で一つを選ばない。
- 回転で重なるだけの状態は同じ状態として 1 つにまとめる（L-06。同じ観測を与える状態なので同点崩しではない）。

### 4.6 停止（決定 6「動かしても変わらない」、I-05）

【推奨】
- 停止: どの 1 手（23 回転＋全ての面の入れ替え）も鍵を厳密に良くしない状態（不動点）。配置がもう動かない、という読み。
- 答える条件: 不動点で §4.4 の一致が成り立つこと。
- 安定度: その状態から 1 手動かしても指す中心 d が変わらない手の割合 inv（正確な分数）。候補の比べ方（§4.7）に使う。
- 変種（事前登録して測る）: inv = 1（どの 1 手でも変わらない）を答える条件に加える。決定 6 をより字義どおりに読むとこちら。どちらを本線にするかが I-05。
- 現行の escape（全断面を全視野にして一度だけ再探索）は使わない。3 行目に無く、断面の一致を形式にする（§2.1 監査の主張）。

### 4.7 読み出しと文の候補（決定 7「言葉を順に読み出して文の候補を作って一番安定状態を採用するか選択方式にする」）

【推奨】（I-13, I-14, I-15）
1. 働く断面 s ごとに、歩いた経路の語を外→中心の順に並べ、最後に d を置く: phrase_s。
2. 文の候補 = 付いた断面の phrase を問い語の順に、続けて付いていない断面の phrase を並べたもの。付いていない断面どうしの順は p（読む順番）で決め、決まらないところは「順序未定」の印を付ける（順序だけ違う候補を別の候補にしない）。
3. 同点の枝や候補の中心ごとに候補ができる。各候補の安定度 = その候補を生んだ状態の inv。
4. 安定度の最大が一つ → `ANSWER`（その候補を採る）。最大が複数で語の集合が違う → `CHOICE`（候補を安定度順に全て出し、採らない）。
5. 出力の全ての語に痕跡を付ける: {段, 層, 中心, 腕, k, 単位, その単位を含む文の sid, 経路の各辺を実証する sid}。

### 4.8 型付きの判定

| 判定 | 意味 |
|---|---|
| ANSWER | 一致した不動点の候補が一つに決まった |
| CHOICE | 一致はしたが、安定度の最大の候補が複数（選択方式）。採点では棄権に数える |
| AMBIGUOUS | 違う中心を指す一致が同じ安定度で複数 |
| UNKNOWN_NO_EVIDENCE | 問い語が空間に無い／働く断面が 0 |
| UNKNOWN_SECTION_DISAGREEMENT | 不動点で断面どうしの指す中心が割れた |
| UNKNOWN_RATIO_DISAGREEMENT | 断面は一致したが R1・R2・R3 が割れた |
| UNKNOWN_NO_FIXED_POINT | 予算内に不動点に着かない |
| UNKNOWN_TOO_MANY_CANDIDATES | 候補の中心が同点で上限を超えた |
| UNKNOWN_UNSTABLE_PLACEMENT | 候補の十字の配置が不安定で、上の層も無い（§5） |

### 4.9 段の統合（I-16）

【推奨】段ごとに独立に周期を回し、段の結果は票に入れず並べて渡す。最終は全段の候補の中で安定度が最大のもの。最大が複数で中身が違えば AMBIGUOUS／CHOICE。段どうしの一致（RUN の中心が CHAR の中心を含む等）は数えて報告するだけ（8 月の階段の格付けに相当、判定には入れない）。

### 4.10 後段の門（I-17）

【推奨】line3 の経路には現行の後段の門（coverage・polarity・配置不変・向き不変・REVERSE_*）を入れない。どれも 3 行目に無い AI の追加。問いとの接地は、R1 の歩きが問い語から始まり実証された辺しか通らないことで構造に入っている。門を付けた変種は事前登録して別に測る。

### 4.11 例の続き（問い「遊眠とは何ですか」、Q = [遊眠]）

ρ_Q は 遊眠・日本・漫画家とも 1。遊眠を +x に付ける。初期状態は §3.6 の鎖 [日本, 漫画家]→遊眠 が +x に向いた十字。
- 初期: R1 は 日本→漫画家→遊眠（比率が下がらない）で d=遊眠。R2: F(漫画家)=2、F(日本)=F(遊眠)=1 → 漫画家。R3: B(漫画家)=2 → 漫画家。指す先が 2 種類 → 一致しない。
- 1 手: 日本（または漫画家）を別の腕へ動かすと星形になる。R1: 付いた断面も付いていない断面も 遊眠 に着く。R2: F(遊眠)=2 → 遊眠。R3: B(遊眠)=2 → 遊眠。一致、働く断面 2。どちらの語を動かすかの 2 手は同点なので両方の枝を辿る。2 つの終点は語の集合 {日本, 漫画家, 遊眠} と中心が同じで、順だけ違う。
- 結果: `ANSWER`、中心 遊眠、文「日本 漫画家 遊眠」（順序未定の印つき）。中心と 漫画家 を入れ替える手では指す中心が変わるので、inv < 1。

この例は、式が動くことを示すためのもので、精度の予想ではない。

## 5. 入れ子（決定 9「エネルギーが安定しなくなったら」、L3-10）【全て推奨】

1. **層を足す時機（I-18）**: §3.4 で `DataCross(c)` の配置が不安定（同じエネルギーで中身の違う終点が複数、予算切れ、容量の境目の同点）になったとき。データが増えて「安定しなくなったら」に当たる。
2. **上の層に載るもの（I-19）**: c の上の層の十字 `U(c)` を作り、下の層で安定に載せられなかった単位（容量を超えたもの、同点で位置の決まらなかったもの）を、同じ §3.4 の手順で配置する。それも不安定ならさらに上へ。現行の「競う腕を上へコピーする」（恒等写像と測定済み (C)）はやめる。
3. **問いの時の流れ**: 第一層で答え（中心 d と読み出した語）が出たら、それを問いの十字として `U(d)` に投入し、同じ周期を回す。上の層で増えた語を付け足す（L3-10「次の層で付け足しや探索」）。上の層が無いか、何も足さなくなったら終わり。
4. **初期の問いを付けるか（I-20）**: 3 行目自身が「焦点」と言っている点。A（初期の問い＋前の層の答え）と B（前の層の答えだけ）の両方を実装し、両方を測って報告する。現行の C（問いの主辞だけ）は比較用に残す。どれを本線にするかはオーナーが結果を見て決める。
5. 第一層が `UNKNOWN_UNSTABLE_PLACEMENT` の候補だけなら、その候補の上の層へ問いを直接入れる（I-18 の (c) を含めるかどうかもオーナーに確認する）。

- 主な数: 正答 C/60、誤答 W60、答えられない問いへの回答 W30、棄権。参考: 緩い正答（主題の条件を外す）、CHOICE のうち正解の語を含む候補があった数（棄権のまま、別に数える）。

### 7.3 データ量の曲線

7 条件 × 全ての系で 7.2 の数を出す。予想は事前に書かない（観測として出す）。A 報告の a1 の値（S300 45/7/8、S269710 43/7/10 (C)）が T0 で再現することを、基準線が正しく動いている確認に使う。

### 7.4 痕跡（全ての出力語が構造へ戻れるか）

L3 の ANSWER と CHOICE の全ての語について、機械で次を確かめる。1 語でも外れたら不具合として止める（合格は 100%）。
1. 語は痕跡の単位と同じ文字列である。
2. 痕跡の sid の文が、その単位を（段の切り方で）含む。
3. 経路の隣り合う 2 語（問い語→最初のセル、…、最後のセル→中心）は、両方を含む sid を 1 つ以上持つ。
4. 出力に空間に無い語が無い（閉包）。

### 7.5 決定論と動きの確認

- 2 回実行して出力が byte 一致。`PYTHONHASHSEED` を 0・1・random で一致。
- 過程の数: 不動点に着いた率、受理した回転と面の入れ替えの数（回転が一度も受理されなければ報告で明記する。F2 の再発の確認）、同点の枝の数、層の数、データ量ごとの不安定な配置の率（決定 9 の振る舞い）、時間。

### 7.6 報告

`experiments/line3/eval/REPORT.md` に表を出す。数値は全て出力ファイルへのパスつき。隠しバンクは使わない。

## 10. 範囲と注意

- この版がしないこと: 記憶（I-24）、ロック（I-23）、10 月の読解器・round5 の修正、現行 legacy 経路の修正。
