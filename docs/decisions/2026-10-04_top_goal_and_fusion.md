# オーナーの決定（2026-10-04）

## 第一の目標
Vera はキラーとなる分野で価値を示し、皆が導入し開発する理由を一つ得て、その完成度で開発を完了する。将来性を見せることが開発を加速させる。

## LLM との融合の位置づけ
LLM と融合する目的は、初期の開発で追いつかない研究時間を短縮し、価値を伝えやすくすること。Vera の開発がさまざまな人や組織で通った後に、フルスクラッチで作り直すか LLM 融合の利点を取るかを比較して主を決める。何も答えられず専用のランタイムが要るモデルは注目されにくい。したがって既定は「答える」で、Vera は出所の型で正直に言う。

## 運用の構成
指示書は Opus 5.5 medium、製品の規則の実装は Sonnet 5.5 medium、長い処理の実装は codex gpt-6-luna max、レビューは Opus 5.5 high、攻撃は codex max、コーパスと枠の生成は codex low。サイトの作成は Opus 5.5 medium。影運用は Vera の検証でもある。
