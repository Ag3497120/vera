## 2. orthoplex の構造と、今のコードが使っていないもの

### 2.1 構造（事実）

3 次元の orthoplex ＝ 正八面体。頂点は ±e1, ±e2, ±e3 の 6 つ。立体十字は「中心＋その 6 頂点への腕」で、次の性質を持つ。

1. **軸の個性**: 腕は 3 本の軸（x, y, z）× 2 つの向き（+, −）。
2. **反対の腕**: +a と −a は中心を通る 1 本の直線。各腕は 4 本と直交し、1 本と反対（中心の裏）。
3. **向き・利き手**: 互いに直交する 3 本の腕の組（8 つの面＝8 象限）は右手系・左手系に分かれる。真の回転（G24、24 個）は利き手を保ち、鏡映を含めると 48。腕の任意の並べ替えは S6 の 720 通りで、そのうち回転は 24、残りの商は 720/24 = 30 通り。
4. **環**: 中心から距離 k の 6 席は、縮尺 k の正八面体を作る（距離 k の席どうしは「同じ環」）。

## 3. 方向 A — 6 軸に基準を置く

### 3.1 基準の候補（オーナーの言葉と既存の決定から導けるものだけ）

各基準は、中心 c と同じ文 s に出る単位 v について、v が腕 a に属するかを決める述語 χ_a(v; c, s) と、腕の上の辺の重み ω_a として定める。全て文から数える整数で、文の番号（sid）を持つ。

## 4. 方向 B — 文法層

### 4.1 文法層とは

文法層 Γ は層 0 とも入れ子（matryoshka）の層とも別の層で、記憶の層（N-16）と同じく問いのたびに別に読む。ソブリンの定義（「同じ粒度のものの集まり」）に従えば、機能語のソブリン。

```
Γ = (F, adj, kind)
F    : 土台の十字（OP-G1-1・OP-G1-3 の答え）。中心 = は（233/377）、6 腕 = の 144/377, に 89/377, で 55/377, と 34/377, を 21/377, が 13/377。
       並びと比率は作られたもの（constructed）。
adj  : adj(v, g) = 単位 v の直後（句読点は飛ばす）に機能語 g が来る文の集合（sid と span つき）。コーパスから数えた記録（record）。
kind : 層 0 の十字（中心 c）の種類 = c の adj の多重集合 {g: |adj(c,g)|}。最多が 1 つなら kind(c) = その g、同数なら tied、無ければ none。
```

- 出所: 助詞の出現と adj は**記録**（コーパスの文、`unit_filter=None` の空間に postings がある。G1 §2.1: 機能語を残すと WORD 3780 単位）。F の並びと比率だけが**作られたもの**。Γ は層 0 の n・N・r0 に入らない（T6v の既定を保つ）。
- Γ は答えの語を出さない（intra2 の正解で全部が機能語のものは 0/69、G1 §2.4(4)、C）。Γ の出力は層 0 を**読む順番**と、候補を**見せる順番**だけ。
- 十字の種類の分布（WORD の異なり、O）: kind が 1 つの助詞 1118（の 297・に 205・は 195・で 130・を 114・と 101・が 76）、tied 178、none 2261（64 %）。

### 4.2 問いのもとで読む順番

1. **Γ を先に読む**: 問いを同じ区切りで切り、(i) 各問いの語 q の直後の助詞（問いの枠）と、(ii) 疑問語の句（何・どこ・誰・いつ … とそれに続く内容語、例「何年」）の直後の助詞 = **空所の助詞 slot** を取る。bank2 fulllead 94 問の問いの内容語の直後: は 81・の 68・で 30・に 29・と 16・を 15・が 13 (O)。

3. 候補の生成・3 つの比率・判定は層 0 のまま。表示の順だけ、候補の語が出所の文で slot の助詞に続くものを先にする（順番だけ。候補の集合は変えない）。

### 4.3 層 0・入れ子・記憶とのつながり

- 層 0: Γ は十字・空間・エネルギーに触れない。B-1 で変わるのは `plan_read` の群の順と表示の順だけ。

### 4.4 最小の試せる版

## 7. 範囲と注意

- しないこと: E_Q の式を変えること（OP-G2-3 (c) の答えが無い限り）、層 0 に助詞を戻すこと、検索との混合（T9 後「十字だけで直して伸ばす」）、軸のロック（I-23）。
